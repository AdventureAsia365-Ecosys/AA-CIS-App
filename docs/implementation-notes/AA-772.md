# AA-772 — Place cards + seed scope (S233, with AA-768 seed items)

## Decisions
- **One card per real place**, not per atom: `place_key = norm(display_name)|norm(locality or region)|norm(country)`
  ("City Palace" Jaipur ≠ Udaipur). `atom_place_card` links an atom to its card (resolved once per atom).
- **Built in jobs, never in HTTP**: T8 (`t8_angles` job, before the seed is read) and T9 (`resolve_facts`, first
  step of the `t9_write` job; the seed is re-read when a new card was built). Soft-fail: no card → old seed.
- **Two models**: `a3_place_card` drafts identity + 6–10 facts (no prices/hours/superlatives/trip claims);
  `a3_place_card_check` (judge route, other vendor) confirms identity and each fact — only "supported" facts are
  kept; identity rejected → no card (tried again next time). Status starts `auto_checked`; admin can set
  verified/rejected (PR 5). Cost on the card row + `llm_call_log` (stages seeded by migration 220).
- **Seed** (`atom_seed.py`): reads `v_active_tour_atoms`; Location from the card (display name, locality, region,
  country + "the itinerary calls it …"), `Naming:` note, `Day N of the trip`, `Place background` facts; siblings
  only same country, no alias, not the same tour, shortest first, labelled "other trips — never promise";
  whole-day-body evidence trimmed to the sentences naming the place (≤500 chars).
- **Scope line** (`SCOPE:`) for every T9 piece: route = days X–Y + places in order, "must not promise anything
  outside these moments, even if the TRIP name does"; single moment = "one moment (day N)".
- **Facts**: filtered by `facts.country` (migration 220) = the trip's country; the per-fact Jev relevance call is
  dropped from T9 (S232: no Jev on the T axis).
- T8/T9 atom reads moved to `v_active_tour_atoms` (CLAUDE.md rule).

## Tradeoffs
- First write for an atom pays ~2 short calls (~$0.01–0.03) and a few seconds; a route blog with 10 new moments
  builds them 4 at a time.
- The checker is an LLM, not a human: cards are "auto_checked" until an admin verifies. Writers may cite them;
  the F9 judge sees them as source.
