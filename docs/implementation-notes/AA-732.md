## Decisions
- Trigger: `deployment_status` (state success, environment exactly `Preview` — checked against the
  GitHub deployments API) + `workflow_dispatch` with `base_url`. Not a required check.
- Vercel preview SSO: "Protection Bypass for Automation" secret (`VERCEL_AUTOMATION_BYPASS_SECRET`,
  set by Nghiệp). The header is added by a `context.route` handler ONLY for the BASE_URL origin,
  never to third-party fonts/CDNs.
- Login: smoke-only Playwright setup project (`smoke-setup`, `auth.setup.ts`) → storageState in
  `tests/e2e/.auth/` (gitignored, never uploaded, deleted at the end of the workflow). Admin user is
  `e2e-claude-code` via `E2E_ADMIN_USERNAME` / `E2E_ADMIN_PASSWORD` GitHub secrets (piped from
  Secrets Manager `aa-cis/dev/e2e-test-admin`, never printed).
- Portal block skips until a tenant test account exists (`E2E_TENANT_API_KEY`, AA-741).
- ESLint kit rules: `error` for the 4 files already clean on the kit, `warn` elsewhere (65 warnings:
  51 raw table, 10 className, 4 modal). The new `frontend-lint` CI job is `continue-on-error` because
  the base already has 74 lint errors in legacy pages — fix under AA-601, then drop it.

## Changed
- 23 legacy e2e specs no longer hold credentials (shared `tests/e2e/helpers/auth.ts`); the leaked
  `e2e-test-admin` user was deactivated in `shared.admin_users` (S220, Nghiệp approved); the dead
  `content`/`content2026` literals removed (that user does not exist).
- Kit: 3 `data-testid`s only (`kit-datatable-body`, `kit-datatable-row`, `kit-empty-state`).

## Tradeoffs
- Screenshots: no reload per shot (viewport + color scheme apply live); desktop full-page, mobile
  first screen only — a 390px full-page list is huge and slow.
- Every wait is bounded (networkidle 15 s, body reads 10 s, skeleton 8 s): polling pages never reach
  networkidle.
