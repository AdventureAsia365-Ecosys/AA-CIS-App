# AA-792 — T2 tenant-voice writer prompt + judge gates on brand fit only

Branch `feat/aa-792-t2-tenant-voice`, stacked on `fix/aa-794-t2-meta` (S235, lane A-T2, Claude
Code). The first commit of the stack (`test: pin A1 writer prompt bytes…`) captured the A1 golden
SHAs on main @20a2387 before any prompt edit; it stays green on this branch.

## Decisions
- **Separate T2 builders, chosen only when `state["is_tenant_rewrite"]`.** `build_s1_system_prompt`
  returns `build_t2_system_prompt(state)` for T2; `build_s1_user_prompt` passes `voice="tenant"`.
  The A1 branch and SYSTEM_PROMPT are byte-identical (golden test: sync + Bedrock Batch, with and
  without a brand, plus the A1 nudge prompt). The Bedrock Batch path is A1-only and unchanged.
- **One rule set, two heads.** SYSTEM_PROMPT was split into pieces (`_RULE_1_CORE_FORBIDDEN`,
  `_RULE_2_BODY`, `_RULES_3_TO_6`, `_RULE_8_AND_OUTPUT`…) and re-assembled byte-for-byte, so
  `T2_SYSTEM_PROMPT` reuses the exact truth/structure rules (rule 1 core forbidden words, rules 2-5
  structure, rule 6 SOURCE FIDELITY, rule 8 meta band) and cannot drift from A1. T2 replaces the
  EDITORIAL VOICE + NEUTRALIZE PROMOTIONAL SOURCE COPY blocks with BRAND VOICE ("write as this
  brand; re-voice the source; the rules below win over the style guide"), rule 2's head says
  "this brand's voice", and rule 7 drops "base catalog" wording but keeps the budget-word ban
  (validate enforces it).
- **T2 system prompt** = T2 base + language + `render_brand_block(pack, heading="CLIENT BRAND")`
  (AA-771, read-only use) + the brand's own `system_prompt` as a "CLIENT BRAND BRIEF" (no "append
  only") + the AA-202 contrast/generic-phrasing rules (factored out of `build_brand_diff_block`
  byte-identically, so the profile is not printed twice) + the AA core + brand forbidden-words
  hard constraint. The brand pack is rebuilt from the graph state (`brand_pack_from_state`).
- **T2 user prompt** (`_USER_VOICE["tenant"]`): opening "as this client brand's own tour page",
  name/summary/day-body ask for the brand voice in EVERY day with the same facts and no neutral
  register, the seo_meta instruction loses the editorial GOOD example. The style guide is NOT
  appended to the T2 user prompt (it is in CLIENT BRAND). Per-day length and SOURCE FACTS blocks are
  unchanged.
- **Itinerary nudge** (`nudge_itinerary_day(..., voice_hint=)`): T2 passes the tenant voice words
  (`nudge_voice_hint`) at both call sites (graph `_process_itineraries` from generate + seed, and
  flag_fix's ITINERARY_STILL_COMPRESSED repair). The T2 nudge says "keep the CURRENT DRAFT's brand
  voice (…)" with no Adventure Asia / "calm, factual, editorial". A1 nudge unchanged (golden).
  Implementation note: the template is filled with `str.replace`, not `.format()` — the shared rules
  end with a literal JSON `{"title": …}` example (caught by the unit test).
- **Brand load** (`t2_rewrite_job._prepare`): `brand_pack.fetch_brand_pack_conn` (AA-771, 'default'
  row first, else newest active) replaces the hand-written SELECT. brand_rules keeps every old key
  and adds `brand_name`, `brand_type`, `default_cta`; `_rewrite_tour` maps them to `brand_name`,
  `brand_type`, `brand_default_cta` in the graph state (declared in ContentState — AA-209 strip
  gotcha). AA-741 kept: a DB error raises; the no-row path keeps `rewrite_language` and
  `_brand_loaded=False`. The T3 repair rounds reuse the same brand_rules, so they inherit it.
- **Judge (Gate-1 default, Nghiệp not answered yet): T2 gates on brand_fit ONLY**, like A1
  (AA-698). `cross_brand_distinct` and `mission_present` are still requested, returned in state and
  logged in `llm_call_log.quality_signal` (plus a new `"gate"` key). **Flip without a code change:**
  env `T2_JUDGE_GATE` on the worker task def — `brand_fit` (default) | `brand_fit_mission` (brand_fit
  capped at 6.0 when the mission is absent; the "keep mission as a gate driven by core_idea"
  option) | `combined` (the S234 rule: min(brand_fit, distinct), mission-capped). The judge prompt,
  `score_brand_fit` call (still passes `mission_absent_cap=6.0`, so A1's call is unchanged) and the
  repeat-median are untouched, so brand_fit stays comparable with S234. Tie-break now keys on
  brand_fit for T2 too.
- **AA core forbidden words still bind the tenant voice (Gate-1 default).** Rule 1 ("luxury",
  "curated", "refined"…) stays in the T2 prompt and validate's `VALIDATE_FORBIDDEN` still fires
  FORBIDDEN_WORD on T2. Flipping this is NOT a one-liner: the prompt piece (`_RULE_1_CORE_FORBIDDEN`
  in `T2_SYSTEM_PROMPT`), `forbidden_words.all_forbidden` (writer hard constraint), validate_node's
  FORBIDDEN_WORD and `forbidden_strip` all read the core list. Note: "luxury" is in the prompt's rule
  1 but not in `VALIDATE_FORBIDDEN` — prompt-banned, never validated (pre-existing).
- **Brand-audit fallback** (plan correction 7): when the judge did not run, a T2 tour is no longer
  audited against `AA_BRAND_IDENTITY_PROMPT` ("calm, assured, selective, private, no hype"). It is
  audited against the tenant's `system_prompt` or the compiled rubric (`brand_pack.compile_rubric`)
  + style guide, with a tenant-neutral user prompt; with no brand at all the LLM audit is skipped and
  only the deterministic pre-audit codes apply. A1 audit unchanged.
- **CTA is not used in the T2 tour**: a tour has no CTA field and `default_cta` is empty for 4/4
  pilot tenants. It is carried in state only for the audit rubric.
- **`is_branded` for T2** = a written system_prompt OR a T0 pack with data (`brand_pack.has_brand`),
  so the `unbranded_generation` warning stops firing for form/.docx tenants. Logging-only field.

## Tradeoffs
- Gating on brand_fit alone may let generic-but-on-voice copy through where distinctness was low.
  Accepted: the distinct axis cannot be answered (the judge never sees another brand's version) and
  S204 showed the reasoning judge scoring it 2-6 vs 8-9; it stays logged for AA-795.
- The brand block repeats the tenant forbidden words (CLIENT BRAND line + HARD CONSTRAINT list).
  Kept: the hard constraint is the one validate mirrors; the brand block is the T8/T9 shared text.
- AA-775 will later change `render_brand_block`'s text (style guide "never a source"), which also
  changes the T2 prompt — intended. The S235 rerun measures the pre-AA-775 text: a known confound.
- Writer + judge change in one release: the rerun cannot attribute a brand_fit gain to one of them.
  Mitigation: the metric is the judge's raw brand_fit (unchanged prompt), not the gated score.
