# AA-1172 — T9 follows an instruction planted in a fact (trap `t9_facts_override`)

Migration PR (CIS 472). The full note (root cause, decisions, tradeoffs) lands with the code PR, which replaces this
file.

## Decisions

- CIS 472 seeds `cis.llm.fact_instruction_guard` (bool, default on, platform, maker-checker, impact high, enforced).
  Number reserved by the S288 lane contract (470 and 471 belong to other lanes); the CI preflight needs them merged
  first, or a renumber (checklist in the migration header).
- `services/ai_safety/fact_guard.py` ships here as the setting's reader (settings-lint rule 2), pure and unused until the
  code PR wires it into the facts read path, the same way CIS 467 shipped `prompt_fence.py`.

## Changed

- Nothing reads the key on main until the code PR deploys; the compiled defaults are regenerated from the seed.

## Tradeoffs

- Default on: a fact with no match reaches the writer byte for byte. If the $0 aggregate over live `acp_shared.facts`
  (run before this PR merges) finds matches that are not instructions, the seed default flips to false here.

## Should know

- `tests/unit/test_aa1172_fact_guard.py` is the two-way keep/drop set (instructions dropped in English and Vietnamese,
  behind zero-width / full-width / look-alike characters; booking, visa, season sentences kept byte for byte).
