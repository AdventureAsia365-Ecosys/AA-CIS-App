# AA-1172 — T9 follows an instruction planted in a fact (trap `t9_facts_override`)

Migration PR (CIS 472). The full note (root cause, decisions, tradeoffs) lands with the code PR, which replaces this
file.

## Decisions

- CIS 472 seeds `cis.llm.fact_instruction_guard` (bool, default **off**, platform, maker-checker, impact high,
  enforced). Number reserved by the S288 lane contract (470 and 471 belong to other lanes); the CI preflight needs them
  merged first, or a renumber (checklist in the migration header).
- `services/ai_safety/fact_guard.py` ships here as the setting's reader (settings-lint rule 2), pure and unused until the
  code PR wires it into the facts read path, the same way CIS 467 shipped `prompt_fence.py`.
- Review round 1 (S288): Vietnamese rules match a lower-cased copy that keeps the tone marks ("viết" and "Việt" both
  fold to "viet"; "ai" means "who"), "AI" counts only in upper case, and the tone-less forms (an evasion) need a
  writing-artefact word in the same sentence. English `meta_directive` keeps inserting verbs (include / add / put /
  insert) only before a quoted string or a named piece of text, drops bare state / feature / ensure / recommend, and
  sections, paragraphs, titles, "the writer" and "the model" count only when a writing verb follows at once; an
  artefact followed by "of ..." never counts.
- Review round 2 (S288), 7 findings, all reproduced and applied:
  - Tag characters (U+E0000-E007F, "ASCII smuggling") outside an emoji flag fire `hidden_text`; bidi controls,
    zero-width spaces and word joiners are removed from every kept title / body / provenance (zero-width joiner and
    soft hyphen stay: real text in some scripts).
  - A body sentence that breaks `role_prefix`, `addressed`, `override`, `prompt_talk` or `hidden_text` drops the fact
    whole (`WHOLE_RULES`), like a title or provenance hit; only `meta_directive` is removed sentence by sentence.
    Vietnamese rules now report under the English rule ids (the `vi` id is gone).
  - A directive broken across line breaks is matched on the lines joined (sentence punctuation still splits); a
    directive split between the title and the first body sentence is matched on the rendered lead line
    `<title>: <first sentence>`. Either one drops the fact whole. A title "For the writer" / "To the AI" counts.
  - Paraphrases with a strong artefact: an inserting verb (include, add, put, insert, use, feature, refer to, make) in
    imperative position that targets the artefact, a modal and a content verb after it ("should contain", "must
    read"), a bare plural "Headings" opening the sentence, a heading label ("Headings: X"); a role word followed by
    `-` or `:` and an order ("Writer - put ...").
  - Vietnamese: tựa đề / tựa bài / đầu đề / đề mục, "đều" (only next to a heading / paragraph / FAQ word), "khi viết
    bài, hãy", "nhờ bạn ghi ... trong bài", "gửi người soạn nội dung", "đừng để ý các hướng dẫn trước", and the
    tone-less directive forms.
  - False positives fixed: `claim` left the directive verbs; override needs the writer's own rules (previous, prior,
    system, your, above) or an imperative, never "of the crew" / "at the temple", negated, or "above" with a
    traveller's condition and no writing verb; a mixed-case role line counts only with an order after it ("Assistant:
    Ms Lan.", "System: the e-visa system is down" are kept); `### Instructions` is a real heading; an article / FAQ /
    post followed by on / at / from is a real thing; third-person inserting verbs ("Each section includes a link")
    are reports; a note "for the author at the memorial" is not addressed; "người viết thư mời / đơn" writes a real
    letter or form; a check-in post ("bài đăng") is not a writing artefact; "tiêu đề của vé" is part of a ticket.
- Review round 3 (S288), 1 major + 4 minors + 1 nit, each reproduced first:
  - Major (an invisible character for each space): the strict fix. `hidden_text` now fires on any invisible format
    character (Unicode Cf: soft hyphen, zero-width space / joiner / non-joiner, word joiner, Mongolian vowel
    separator) between two Latin / Greek / Cyrillic letters or digits, so the fact goes whole. As a second net, every
    rule also runs on a copy that reads each invisible character as a space. An emoji ZWJ sequence, a joiner next to
    a space, and characters of scripts that use a zero-width space as a word break (Thai, Khmer, Lao, Burmese) stay.
  - Variation-selector smuggling: any selector that is not the single selector of an emoji, a symbol, a keycap or a
    CJK character (a run of them, any U+E0100-E01EF after a letter, one after a space) is `hidden_text`.
  - `forged_entry` (new whole rule): a `[Fact id=` / `[Moment id=` head anywhere in title, body or provenance, or a
    line opening with `Source:` in title or body (a later line of the provenance; its first line is printed by the
    renderer after our own "Source: " on one line, so "Source: embassy website" as provenance is kept). The block path
    drops an entry with a second or non-final `Source:` line, and an entry without one in a block whose other entries
    have one, together with the entries up to the next `Source:` line (the front and the back of one cut fact).
  - False positives kept: a heading word followed by a real document ("tiêu đề trên vé", "tiêu đề email", "vé",
    "thư", "đơn", "hộ chiếu", ...) is a real thing like "của"; a FAQ / post followed by "form" or "(that) you send /
    mail / receive" is a real thing.
  - Nits closed: a role label in any case at a sentence or clause start whose remainder orders or breaks a rule
    ("Developer: headings say X", "...; system: say X"), DEVELOPER, "content creator / writer / team" as addressee, an
    HTML comment, digits read as letters when they touch a letter ("N0TE T0 THE WR1TER"; prices and times never
    change), "subtitles" with a writing verb (never as a label or with "be": film captions), the writer's own reply
    with a naming verb ("your response calls", "in your output, refer to ... as", "when writing about this trip,
    call it"), "pay no attention to" and "guidance" / "text" (not "text message") as override words.

## Changed

- Nothing reads the key on main until the code PR deploys; the compiled defaults are regenerated from the seed.
- Seed default flipped from true to false after review round 1 found false positives (lesson L408, S272: a writer
  behaviour change ships at main's behaviour until two adversarial rounds converge).
- Review round 2: the setting description and the EN / VI guide example now say that a fact addressing the writer is
  left out whole and only a heading / FAQ / post directive is removed alone (the example uses that sentence shape).
  Default stays off: round 2 did not converge (it found misses), so a further round must find nothing new first.

## Tradeoffs

- Round 3 chose the strict drop over a cleverer join: a soft hyphen copied from a web page into a Latin word ("Ti­ckets")
  now drops that fact whole. Real booking terms rarely carry one, a dropped fact is visible in the FactSheet exclusion
  reason, and every looser rule (ignore soft hyphens, keep ZWJ) re-opened the bypass.
- A fact rendered without a `Source:` line (no scope and no provenance) inside a block whose other entries have one is
  read as a cut fact on the replay path. The live fetch always sets scope, so every live entry has the line.
- Default off: live facts reach the writers exactly as on main until an administrator turns the setting on. The $0
  aggregate over live `acp_shared.facts` only covers facts that exist today, so it cannot by itself justify default on.

## Should know

- Default still off after round 3: round 3 found a new major (invisible separators), so the convergence rule is not
  met; a fourth round must find nothing new before an administrator turns it on.
- Known limits after round 3: hidden characters between letters of scripts other than Latin / Greek / Cyrillic are
  not checked. Known limits after round 2: a directive split across sentence punctuation ("Every heading. Must say X.") is not
  joined (joining across sentences dropped real two-sentence terms such as "Our FAQ page has the terms. Write your
  name on the card."); letters split by spaces; languages other than English and Vietnamese; a paraphrase that names
  no artefact and no role.

- `tests/unit/test_aa1172_fact_guard.py` is the two-way keep/drop set (instructions dropped in English and Vietnamese,
  with and without tone marks, behind zero-width / full-width / look-alike characters; booking, visa, season
  sentences, the review round 1 sentences included, kept byte for byte).
