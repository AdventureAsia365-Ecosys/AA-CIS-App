# F9 sticky pass: carry a pass through a repair edit (S245, 20/10/2026)

Agent: Claude Code (lane f9fix). Evidence: the root audit `docs/audits/2026-10-20-S245-f9-pooled/` (pool.json,
the case classification in its README §5, and the counterfactual replay script).

## Decisions

- **Fix (a), not (b).** The pooled dump shows F9 re-judging (class C2) is the largest class in the primary pool
  (5 of 8 retry-added fails; 3 are real new faults, none is a two-sentence quote). Option (b), "F9 on a repaired
  sentence warns instead of blocks", would let a repair-added claim ship and conflicts with the writer
  source-fidelity policy. Option (a) only stops F9 from judging again what an earlier verdict of the same piece
  already passed.
- **Where the memory lives.** The job's sticky-pass set becomes `F9PassMemory`, a `set` subclass that also keeps
  `last_text`: the tag-free body the last F9 verdict judged. `gate_brand_voice` carries passes from that text to
  the current one before it drops sticky claims. A plain `set` (tests, any other caller) keeps today's behaviour
  exactly, and so does attempt 1 (no `last_text` yet).
- **What "not changed by the repair" means (deletion-only).** A new sentence keeps the pass of the old one only
  when its words are the old words in the same order with some removed (`_f9_deletion_only`):
  - every removed run is made only of filler adverbs (`also`, `very`, `truly`…) or ends at a punctuation break:
    a start run needs a break before the first kept word ('Unlike the southern route, the drive…'), an end run a
    break before the first removed word ('…of 1937: a single, spare reminder…'), a middle run a break on both
    sides (an appositive or a parenthetical). A run removed from the middle of a phrase ('the museum near the
    monastery founded in 1586' → 'the museum founded in 1586') can re-attach a modifier, and a start or end run
    cut without a break can drop a qualifier ('Lunch is included on most days of the trek.' → 'Lunch is
    included.', 'The museum is open daily in summer.' → '…open daily.'), so both are judged again;
  - no negation, hedge, option or quantifier word is removed (`not`, `optional`, `can`, `about`, `if`, `said`,
    `most`, `least`, `per`, `each`, `all`…): dropping one makes a stronger claim;
  - no symbol is new (the `_f9_key` rule: '12' → '12+' is a new claim).
  A style edit that swaps or adds a word ('exerts a gravitational pull' → 'shapes') is judged again.
- **Referent openers.** A sentence that opens on a referent word (`_REFERENT_OPEN_RE`) keeps its pass across a
  change of the sentence before it only when the antecedent is kept: the previous sentence is the same, or a
  deletion-only edit of the old one, or, for a definite noun phrase opener ('The sacred cave…'), every content
  word the sentence shared with its old previous sentence is still in the new one. A pronoun opener ('It was
  founded in 1692.') after a rewritten neighbour is still judged again (the r6 fix 3 / r7 review protection).
- **Sentence alignment.** `difflib.SequenceMatcher` over the folded sentence lists of the two texts: an equal
  block maps one to one; in a replace block each new sentence is compared with every old sentence of the block.

## Tradeoffs

- Deletion-only is strict on purpose. It clears the r6 deletion case and the r7 unchanged-sentence case, but not
  the r7 style rephrase ('exerts a gravitational pull' → 'shapes', 'sustained') and not the r5
  'stand within this region' rewrite ('within' is new). Accepting synonyms would need a judgement the code cannot
  make safely, and the policy says never ship an unjudged new claim.
- The definite-noun-phrase rule relaxes the r7 review's choice for one shape only: the opener names its own
  subject, and the words it shared with its old neighbour must survive. 'We visit Taktsang Monastery. The
  monastery was founded in 1692.' after 'We visit Kyichu Lhakhang.' loses 'monastery', so it is judged again.
- The carry costs no LLM call; it is one sentence diff per F9 verdict after attempt 1. A word-set check runs
  before the in-order alignment, so even a full rewrite (every sentence replaced) stays well under a second
  (0.4 s measured on two unrelated 80-sentence texts built from a 20-word vocabulary, the worst case).
