# AA-863 — Show the Slate seed place and country next to each Subject and T9 piece

Admin only. Content Quality (`/admin/content-quality`, Pieces tab + piece drawer) and the
atom-curation Slate tab (`/admin/atom-curation?section=slate`) show, per row, the seed atom's place
and country, the Segment label, and a warning badge when the seed does not fit the Subject.

## Decisions

- **One rule module, no re-implementation.** `services/acp_shared/seed_audit.py` holds the pure
  check (`seed_check`) and the batched reads. The place check calls
  `subject_seed.match_grade()` with the same alias-card map the Slate uses
  (`subject_seed.load_alias_cards`), so "matches" here means exactly what `choose_representative`
  accepts (any grade 0-4, the loose word-set tier included).
- **Which seed.**
  - T9 piece: `angle_gate_request.atom_id` (the frozen seed the writer was given), read from
    `acp_contract.tour_atoms` (not the active view, so a seed whose tour later left the active set
    still shows its place).
  - Subject (Slate row): the latest `angle_gate_request.atom_id` for that Subject when it was picked
    (`source: "request"`), else the seed a pick would use now (`source: "computed"`), from
    `choose_representative()` over `load_segment_members()` + the tenant's tours — the same inputs
    `_resolve_representative_atom()` uses. No seed → `skip_reason` (the `subject_seed.SKIP_*` code).
  - Route Subject: the Route anchor rule, extracted from `slate._resolve_representative_atom` into
    `subject_seed.choose_route_anchor()` (behaviour unchanged) so admin and pick share it.
- **"The Segment's country"** = the distinct known countries of the Segment's live, non-alias
  members on `owner_scope IN ('platform', <tenant>)` (what the seed rule itself sees). A Route's
  country = its tour's country.
- **Mismatch flags.**
  - `place_mismatch`: Segment Subject, a seed and a Subject place, and `match_grade(...)` is `None`.
  - `country_mismatch`: seed country known, Segment countries known, and the Segment's country set
    is not exactly `{seed country}` — so a still-mixed Segment (several countries) is flagged too,
    because there is no single "Segment country" the seed can agree with.
  - Route Subjects: country check only (the anchor may legitimately be any member of the Route's
    first Segment on that tour; a place check would flag by design).
  - Unknown seed country (tour without country) is not flagged (the seed rule also accepts it for a
    name match); the UI shows "country unknown".
- **Segment ids that merged** resolve to the live id (`resolve_segment_aliases`) before the label /
  country read, same as the Slate and pick do.
