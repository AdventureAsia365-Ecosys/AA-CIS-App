# AA-740 — Deterministic seo_meta / seo_title length fit after the last LLM repair

## Decisions

- **Two positions, same as AA-738:** the fit runs at write time (`_apply_seo_meta_fit`, before
  validate) and again at the start of `revalidate_node` (after flag_fix / `_rerepair_meta` /
  grounding repair). If the strip or the fit changed anything there, the content is re-validated
  even when flag_fix did not apply, otherwise the old codes would still block Master.
- **Too long:** the existing salvage (complete-sentence prefix) first; then cut at the last clause
  boundary (`; `, ` — `, ` – `, `, and `, `, `) that leaves 139–154 chars, drop a dangling
  connector, end with a period, require `meta_complete_sentence`.
- **Too short:** append one clause built only from tour facts (duration in days parsed from the
  raw `duration`, country), e.g. "…, over 14 days in Sri Lanka." — no filler words. Several
  phrasings are tried in a fixed order; the first that lands in band wins.
- Anything that still misses the band is returned unchanged → the hard code stays (Nghiep S217:
  hard codes block Master).
- **seo_title:** `fit_seo_title` (AA-639, T2) moves to `seo_meta_utils` (neutral module) and
  `tenant_pipeline` re-exports it; the S1 path now uses it too.
- **Write-time trim removed** for seo_meta / seo_title: both columns are unbounded `varchar`, and
  the trim made the stored meta differ from the validated one (S218: stored 153, code TOO_LONG).
  Approved rows are in band anyway; review rows now show the real text.

## Changed

- `seo_meta_utils.py`: `fit_seo_meta_final`, `tour_days`, `fit_seo_title` (+ `SEO_TITLE_MAX`,
  separators) moved here; `tenant_pipeline` re-exports them (T2 behaviour unchanged).
- `graph.py`: `_apply_seo_meta_fit` uses the final fit + title fit and returns whether it changed
  anything; `revalidate_node` runs strip + fit first and re-validates when either changed content.
- `admin_pipeline.py`: write-time trim of seo_meta / seo_title removed (`_trim_to_word_boundary`
  stays, still unit-tested, no caller on the write path).
- Tests: `tests/unit/test_aa740_seo_length_fit.py` (16).

## Tradeoffs

- The word-boundary fallback can end a meta on a shorter phrase ("…National Parks with luxury
  transfers."). It is a complete sentence in band, which beats a blocked tour; the LLM repair still
  runs first, so this only kicks in when the repair missed.
- The fact clause ("…, over 14 days.") is plain. Facts only, so it can never invent a claim
  (grounding, ADR 0007).
- Re-validating after a deterministic edit costs one judge call for those tours.

## Should know

- A meta far from the band (e.g. 82 chars) is still blocked by design.
