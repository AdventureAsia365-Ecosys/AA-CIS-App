# AA-105 — Master Content Detail Panel v2 + Compare + Brand Identity Cleanup

## Decisions
- TourDetailPanelV2 and CompareModal extracted to shared `_components/` — both master-content and s1-rewrite use them
- EditableField is fully self-contained (manages own save state + last-saved ref to avoid double-saves on blur)
- Auto-save on blur (not explicit Save button) — toast appears per-save
- src_highlights / aa_highlights: textarea newline-separated → string array on PATCH
- seo_keywords_used: textarea comma-separated → string array on PATCH
- JSONB fields in PATCH use `::jsonb` cast in SQL SET clause
- Compare tab content tabs (Summary/Highlights/Itineraries/SEO) are in modal header, shared across columns
- Synced scroll uses isSyncing ref to prevent infinite loop
- get_tour_detail backend updated to include period, provider, inclusions, exclusions (were missing from SELECT)
- History tab: spec asked for SEO Mode + Brand Version columns — not stored per generated_content row in DB; added Model column only; SEO Mode/Brand Version skipped (no schema change)
- Published tab: aa_summary not in published_tours schema — shows aa_name, aa_subtitle, quality_score, published_at only

## Changed
- Panel width: fixed px → 70vw
- Backdrop: transparent overlay → rgba(0,0,0,0.4), backdrop now inside the panel component
- Master-content detail panel: 1 view → 4 tabs with editing
- S1-rewrite detail panel: 3 tabs → 4 tabs with editing
- Upload S0: removed Brand Identity tab and sub-tabs, removed tab bar, added link note to /admin/brand

## Tradeoffs
- Shared component reduces code but means both pages import from _components (cross-route dependency)
- Auto-save on blur (not debounced) — fast typists may see multiple saves if they blur mid-edit; acceptable for admin tool
- No re-fetch after save — initialValue stays at original load; "last saved" ref prevents redundant saves

## Should know
- PATCH /admin/tours/{tour_id}/raw whitelist = 13 fields; PATCH /admin/tours/{tour_id}/generated/{id} whitelist = 8 fields
- Both PATCH endpoints check whitelist before building dynamic SET clause (no SQL injection risk)
- In compare modal, tourIds.slice(0,4) enforces max 4 columns
- CompareModal z-index 300 (above TourDetailPanel at 200)
