## Decisions
- Rates: Haiku 4.5 $1/$5 (verified vs CE, not only list price). Cache write 1.25x / read 0.1x of
  input (Anthropic 5-min TTL rates; only TTL prompt_cache.py uses).
- `LLMClient._calc_cost` now delegates to `pricing.calc_cost` — one formula, not two copies.
- `_SHORT_KEY_TO_MODEL_ID` also maps `haiku-4-5`/`sonnet-4-6`/`satellite-*` labels so a call site
  that passes `resp.model_used` into `calc_cost` is priced right instead of hitting the Sonnet
  fallback.
- Search Demand logs with `role="writer"` — `llm_call_log.role` has CHECK (writer/judge/validate,
  migration 137); a new role name would be rejected and swallowed by record_call's try/except.
  Found while writing the fix, not by a failing test.
- No `stage=` added to the Search Demand LLMRequest (would change model routing via role_config);
  only the log row gets `stage="a3_search_demand"`.

## Data fix — historical Haiku rows (approved by Nghiệp, S196)
Script `.tmp-session/aa635_reprice.py` (workspace root, gitignored): `UPDATE shared.llm_call_log
SET cost_usd = <$1/$5 formula> WHERE model ILIKE '%haiku%' AND cost_usd = <old $0.25/$1.25
formula> (±0.000002)`. Self-selecting + idempotent; reversible without backup (old value = old
formula on the same tokens).
- Dry-run (rolled back), 24/09: 1438/1438 Haiku rows matched, 0 NULL; after: 17/09 acc3 $6.1846,
  21/09 acc1 $0.0361 (= CE), 21/09 acc3 $0.3783 (= CE); 0 rows left at old rate.
- Commit run: first blocked by the Claude Code auto-mode permission classifier; run after Nghiệp
  explicitly issued the command → `UPDATE 1438`, `COMMITTED`, 0 rows left at old rate.
- Live re-check 16–22/09 (taskDef 330): CE Bedrock acc3 $25.9941 / acc1 $0.7660; llm-usage/tree
  acc3 $25.7855 (−0.8%) / acc1 $0.0361 (17/09 $0.73 sits in acc3, documented). AA-635 → Done.
