# AA-196 — Day-by-day titles must name place/activity

[AA-193·F4] String-format spec + deterministic audit validator. **NO schema change.**

## Decisions
- **itineraries stays a single STRING** (`"Day N -- [title] + prose"`). Locked decision —
  converting to a structured list would ripple across generated_content / S2 / S3 / blog /
  exports / UI. Validator works on the joined string.
- New failure code: **`ITINERARY_DAY_TITLE_GENERIC`**, routed to field `itineraries` for fix.
- Detection is a **deterministic regex** in `pre_audit_checks` (same contract as AA-195's
  `ITINERARY_MEAL_TIME_INVENTED`), not an LLM judgement — cheap, reliable, no token cost.
- Regex anchored with `re.MULTILINE` + `$` so each `Day N -- ...` line in a multi-day string
  is checked independently. Generic words (`Exploration|Free Day|Arrival Day|Arrival|
  Departure|Transfer`) only trip when they are the **whole** title (line ends right after).

## Changed (4 prevent + catch layers)
1. `services/content_generation/prompts.py` — STRICT RULE 5 now mandates each day title name
   place/activity with GOOD/FORBIDDEN examples; OUTPUT JSON FORMAT itineraries hint updated.
2. `services/content_generation/brand_standards.py` — AA_ITITERARIES day-title spec added;
   `ITINERARY_DAY_TITLE_GENERIC` added to FAILURE CODES list.
3. `services/content_generation/brand_audit_node.py` — `ITIN_DAY_TITLE_GENERIC` regex +
   append in `pre_audit_checks`.
4. `services/content_generation/flag_fix_node.py` — `STAGE2_FIX_MAPPING` maps code → `itineraries`.

Tests: `tests/unit/test_aa196_day_title.py` (9 tests) — mirrors AA-195 test style.

## Tradeoffs
- **Whole-title-only matching**: "Day 2 -- Exploration of the Mae Taeng Valley" is NOT flagged
  (it names a place). Chosen to avoid false positives on legitimate descriptive titles that
  happen to start with a generic word. A title that is ONLY a generic word is the clear failure.
- **Regex over LLM**: misses subtler generic titles ("Day 2 -- Leisure", "Day 2 -- Sightseeing")
  not in the keyword list. Accepted for v1 — list is easy to extend; LLM judge still runs on top.
