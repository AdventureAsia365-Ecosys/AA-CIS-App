## Proposal (pending decisions A–D on the page)
- One shared `app/_brand/tokens.ts`; `A` and `T` read from it, keeping their existing names.
- accent `#DB9628` / accentDeep `#9E6E16`; separate `danger #C20101`; one success `#2E7D5B`.
- Fahkwang (titles, big numbers) + Poppins (UI); JetBrains Mono kept for IDs/numbers.
- Pill buttons, primary uppercase; real logo in both sidebars; "ADMIN" tag replaces red for
  admin-only nav items.
- Rollout: PR 1 shared tokens + admin, PR 2 portal; screenshot all 27 pages on Vercel preview.

## Decisions
- Portal included in scope (Nghiệp, S196: "đồng bộ cho cả trang portal tenant").
- Nghiệp approved A–D as proposed ("Đồng ý hết").
- `A.red` / `T.red` keep their names and now mean danger only (#C20101). Only the ~30 admin uses
  that meant *accent* (primary button, active nav/tab/plan picker, page-header icons, neutral
  chips, links, spinner) were moved to the new `A.accent`; every error/failed/delete use keeps
  `A.red`. Cheaper and safer than renaming 150 call sites.
- Big stat numbers use Poppins 600 + tabular figures, not Fahkwang: in the visual check
  Fahkwang's "0" read like a letter "O". Titles stay Fahkwang. (Small deviation from decision C.)
- Sidebars 220 → 236px: with Poppins + the ADMIN tag, labels wrapped/truncated at 220.
- Logo served from `/assets/…`, NOT `/brand/…`: middleware matches `/brand/:path*` (internal
  Brand page) and redirected tenants / logged-out visitors → broken image on login pages.
- Login pages (`/login`, `/tenant-login`) included in PR 2 — they are the first brand touchpoint.
- Emoji quick-action tiles on the portal dashboard → lucide icons (off-brand, and blank where no
  emoji font).

## Tradeoffs
- Poppins is ~8–10% wider than IBM Plex Sans → dense admin tables may wrap more (decision C).
- Fraunces + IBM Plex Sans still loaded: `(internal)` routes (`internalUi.tsx`, upload, review)
  hard-code them. Out of AA-605 scope; drop the fonts when those routes move to the tokens.
