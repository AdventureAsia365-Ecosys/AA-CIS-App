# AA-771 — Tenant brand pack everywhere (T8 / T9 / T10)

## Decisions
- **Deterministic pack, no LLM compile** (Nghiệp, S233). `services/acp_shared/brand_pack.py` reads the
  active `shared.tenant_brand_rules` row and renders it at request time — always the tenant's latest T0 save.
- **`default_cta`** (migration 220, Nghiệp S233): the CTA when neither the request nor the write call has one.
  Form field "Default Call to Action" on the portal T0 page and the admin tenant Brand tab.
- **F9 rubric**: `system_prompt` (hand-written) still wins; otherwise a rubric compiled from the T0 fields;
  no T0 brand content → `NEUTRAL_RUBRIC` (judges clarity/CTA only). `AA_BRAND_IDENTITY_PROMPT` is no longer
  a fallback for tenants. Only T9 calls `fetch_brand_rubric_text`.
- **T8**: gets the brand block + the channel block (the channel is always known since the Slate; AA-469's
  reason for dropping it no longer holds). `best_final_style` is now a brief bound to the seed.
  Angle contract check (deterministic): another brand / the platform name / a tenant forbidden word in an
  angle → one regeneration with that feedback. Tenant forbidden words also count as ranking avoid-list hits.
- **T9**: brand block replaces the AUDIENCE/MINDSET/BRAND NAME lines and the invented "discerning
  travellers" default. Brand name: T0 `brand_name` first, `shared.tenants.name` fallback.
  Core idea added to the gate source (`_grounding_text`) so the brand's own stated approach is not an
  "unsupported claim".
- **New blocking, repairable gates**: `F2_brand_forbidden` (tenant forbidden words; exempt when in source) and
  `F11_brand_name` (another brand speaking — "At X, we…" — or Adventure Asia / AA). Both go through sentence
  repair (quoted sentence in the violation).
- **Goals / channel styles** rewritten in neutral English (were Vietnamese with AA positioning and "premium",
  also shown in the tenant goal picker). Blog structure: CTA paragraph before FAQ. Social channels get a
  plain-text rule + deterministic markdown strip.

## Changed
- `fetch_brand_audience` now returns the whole pack (`BrandAudience = BrandPack`), so every existing caller
  gets the extra fields without signature changes.

## Tradeoffs
- The brand-name detector only flags "At <Name>, we/our/us" frames and AA/Adventure Asia; names in the source
  (places) are skipped. On the 49 S232 pieces it flags exactly the 2 invented brands.
- Contract check is deterministic only (no LLM check of "scene not in seed"); the prompt carries that rule.

## Should know

- Existing angles in Dev still contain "AA" (stored S232 angles) — regenerate the measurement angles.

# S234 PR3 — T8 angle contract + LinkedIn register (branch feat/aa771-voice-angle-contract)

Stacked on PR2 (feat/aa768-hygiene-scope-seed) — reuses `hygiene.autofix` (hashtag cap / first-line
split wait for this PR's channel spec), `atom_seed.moment_fact_count` / thin tag, and the
`F15_voice` entry PR2 already put in `sentence_repair._ELIGIBLE_GATES`.

## Decisions
- **One deterministic spec module** `services/acp_shared/channel_spec.py`: brand register (voice
  adjectives first, then brand_type keywords), `linkedin_spec(pack)`, voice axes, the stock-phrase
  hard list and `sanitize_best_final_style`. T8, T9 prompt and T10 gates all read it (one value, one
  function). Only LinkedIn has a spec; other channels keep their `channel_style` row unchanged.
- **Blog writer prompts stay byte-identical** (system + user prompt). Guard test pins sha256 of the
  blog prompts computed on the PR2 base before any PR3 edit. Therefore the T9-time sanitiser and the
  VOICE / length lines apply to non-blog channels only; blog angles get the sanitiser at T8 persist time.
- **Registers** (deterministic, voice adjectives decide first): consumer_social (voice has
  energetic/fresh/playful… or brand_type young/active/social), editorial (luxury/premium/cultural and not
  family), warm_practical (family), observational (default). Pilot: Trail Pulse / A&H / Terra / WildKind.
  Gate word band 120–250 (editorial 120–300); prompt target 150–220 for every register (lesson: LLMs
  overshoot counts — target below the gate band); hashtags ≤3; first line ≤140 chars.
- **Sanitiser (C7)** is sentence-level, not clause-level: probing the S233 briefs, clause-level stripping
  left dangling fragments ("1937 — without explaining it…", "Frame this not as…"). A tone sentence is cut
  only when a tone word sits on the opposite pole of the brand voice (axes energy / warmth / formality;
  negated words ignored); "Tone: calm, intelligent" stays for A&H (Calm is its voice). "Open with …"
  sentences are cut (a ", then …" tail is kept). Audience-of-professionals sentences are cut for
  non-editorial brands only. Never returns an empty brief.
- **Thin anchor (C7)**: a Route request's T8 seed is now a digest of the whole walk (day order, fact count,
  top 2 facts, ANCHOR CANDIDATES / THIN MOMENTS), built from `content_writing.service._fetch_route_segments`
  (same merged, day-sorted blocks T9 uses — imported lazily: content_writing.service imports the T8 service).
  `route_digest.angle_anchor` = earliest mention of a moment's own name word or its "Day N" in the angle
  name, then in the brief's lead/open sentence (detected on the RAW brief, before the sanitiser cuts the
  "Open with" sentence). One thin angle → ranked last (`RankedAngle.score` gets a leading thin flag); all 3
  thin → one retry with the reason (same single retry as the brand contract). The thin flag is never put
  in the tenant-visible `violations` column (tenants see content only) — logged only.
- **F15_voice blocking** only for the stock-phrase hard list (`F15_STOCK_BLOCKING=True`, plan PR3: "goes to
  sentence repair"); B2B register / segment leak / generic or repeated opener are warn. When it blocks,
  every F15 violation is repaired sentence-by-sentence (all quote a locatable sentence; a <4-word sentence
  is quoted with the next one so `locate_sentence` finds it). F14_social_shape blocks only above 1.3× the
  band top (325 / 390 editorial) → full rewrite with the explicit target in the feedback.
- **Scope of F14/F15**: LinkedIn only (the only channel with a spec). Other channels pass both gates.

## Review fixes (S234, fix commit after 4a13d6d)
Six findings, all verified by reproduction; all fixed.
- **Thin anchor (route_digest.angle_anchor).** The brief's lead text now drops every clause that keeps a
  moment out of the lead (negation: not/never/avoid/instead of/rather than…; limiting: "one sentence",
  "at most", "briefly", "in passing"), then picks the moment right after a lead verb ("lead/open/start/hook/
  anchor … with|on|in X"), else the earliest one named. The angle name still wins first. "Keep the ruins to
  one sentence at most; lead with … Lake", "Avoid anchoring on the ruins. Lead with the lake…" now anchor on
  the lake, so compliant angles no longer rank last or trigger the paid all-thin T8 retry.
  Decision: no "prefer non-thin when both appear" rule — it would hide a real "Lead with the ruins, then the
  lake" brief.
- **F15 split.** `gate_voice` → `F15_voice` (stock hard list only, repairable). New `gate_voice_warn` →
  `F15_voice_warn` (trade register, audience-number leak, generic/repeated opener; never blocking, never
  repairable). `sentence_repair.plan` therefore only ever rewrites the stock sentences. Ledger grows by one
  entry for every channel (passes without a spec); highlights + `shared.ts` label added.
- **F15 never holds, repairs at most once.** `run_quality_gates(stock_blocking=…)`: the T9 loop passes
  `attempt == 1`, so a stock phrase blocks only on attempt 1 (one sentence repair). `quality_gates.hold_failure`
  (first failed blocking gate not in `STYLE_ONLY_GATES`) decides the hold in both hold sites of the loop
  (`service._hold_or_ship`); when only F15 is left the piece ships `approved` with F15 added to `flags`
  (non-blocking). Decision: kept the stock list blocking on attempt 1 (plan §4 routes it to sentence repair,
  which only runs on blocking gates) rather than making it warn-only.
- **Stock patterns narrowed.** `tells you something (about|important)` (no "everything"); `no accident` only
  as `(it's|it is|it was|is|was|this is|that is) no accident`.
- **Trade register (shared `TRADE_PATTERN` = `B2B_RE` = sanitiser audience pattern).** No bare
  operators/planners/advisors/professionals. Adds: speaking as an operator ("as an operator", "a thoughtful
  operator"), "plan or recommend", "recommend/sell/package … travel", "put travellers in it", "your clients",
  "fellow/other operators|brands", "professionals planning…". Kept: "local boat operators run the crossing",
  "guides and planners handle…", "parents and family trip planners…". Decision: no bare "practitioner"
  (Bhutan content has "traditional medicine practitioner").
- **Opening instruction rewritten, not cut.** "Open/Start/Begin with|on X" → "Lead with X"; "Do not open
  with X" → "Do not lead with X" (keeps the framing guard and its "; …" tail); "Open: X" → "Lead with X". Only
  a literal first line is cut ("Opening line: …", `Open with "…"`), keeping a following ", then …". The verb
  prefix is restricted to adverbs/negations, so "Lead with open water on Day 2" is untouched (the old pattern
  turned it into an opening sentence).
- Offline replay on the 41 stored LinkedIn pieces (scratch `replay.py`, local JSON only, no DB/LLM):
  F15 blocking 16/41 (was 17 — narrowed patterns), sentence-repair items 22, all stock-only; trade-register
  warn 9 (was 6); 6 of the 7 distinct stored briefs change, 0 fall back to the generic brief, every "Open with"
  detail survives as "Lead with".
- Tests: 2 sanitiser parametrised sets (7 real/synthetic briefs keep their detail, 3 trade briefs cut, 3
  content briefs kept), literal first line, 5 thin-anchor briefs, lead-verb priority, no all-thin retry on
  compliant angles, stock-only repair plan with warns present, ordinary sentences not stock, `hold_failure` /
  `_hold_or_ship`, and a T9 loop test (stock phrase left after the repair → approved, `stock_blocking`
  [True, False]).
