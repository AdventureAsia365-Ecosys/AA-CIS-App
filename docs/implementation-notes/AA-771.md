# AA-771 — Tenant brand pack everywhere (T8 / T9 / T10)

## Decisions
- **Deterministic pack, no LLM compile** (Nghiệp, S233). `services/acp_shared/brand_pack.py` reads the
  active `shared.tenant_brand_rules` row and renders it at request time — always the tenant's latest T0 save.
- **`default_cta`** (migration 220, Nghiệp S233): the CTA when neither the request nor the write call has one.
  Form field "Default Call to Action" on the portal T0 page and the admin tenant Brand tab.
- **F9 rubric**: `system_prompt` (hand-written) still wins; otherwise a rubric compiled from the T0 fields;
  no T0 brand content → `NEUTRAL_RUBRIC` (judges clarity/CTA only). `AA_BRAND_IDENTITY_PROMPT` is no longer
  a fallback for tenants. Only T9 calls `fetch_brand_rubric_text`.
- **T8**: gets the brand block + the channel block (the channel is always known since the Slate; AA-469's
  reason for dropping it no longer holds). `best_final_style` is now a brief bound to the seed.
  Angle contract check (deterministic): another brand / the platform name / a tenant forbidden word in an
  angle → one regeneration with that feedback. Tenant forbidden words also count as ranking avoid-list hits.
- **T9**: brand block replaces the AUDIENCE/MINDSET/BRAND NAME lines and the invented "discerning
  travellers" default. Brand name: T0 `brand_name` first, `shared.tenants.name` fallback.
  Core idea added to the gate source (`_grounding_text`) so the brand's own stated approach is not an
  "unsupported claim".
- **New blocking, repairable gates**: `F2_brand_forbidden` (tenant forbidden words; exempt when in source) and
  `F11_brand_name` (another brand speaking — "At X, we…" — or Adventure Asia / AA). Both go through sentence
  repair (quoted sentence in the violation).
- **Goals / channel styles** rewritten in neutral English (were Vietnamese with AA positioning and "premium",
  also shown in the tenant goal picker). Blog structure: CTA paragraph before FAQ. Social channels get a
  plain-text rule + deterministic markdown strip.

## Changed
- `fetch_brand_audience` now returns the whole pack (`BrandAudience = BrandPack`), so every existing caller
  gets the extra fields without signature changes.

## Tradeoffs
- The brand-name detector only flags "At <Name>, we/our/us" frames and AA/Adventure Asia; names in the source
  (places) are skipped. On the 49 S232 pieces it flags exactly the 2 invented brands.
- Contract check is deterministic only (no LLM check of "scene not in seed"); the prompt carries that rule.
