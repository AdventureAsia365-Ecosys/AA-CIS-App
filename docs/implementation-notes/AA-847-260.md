# AA-847 — migration 260: place stages on Claude Haiku 4.5

## Decisions
- **Model:** the owner chose Haiku 4.5 for `a3_place_days` and `a3_place_locate` (S246). The only options he allowed were
  Haiku or Luna, and Haiku 5.5 cannot be called on acc3 yet: Bedrock's Marketplace subscription is refused, even for
  the account admin.
- **Fallback `sonnet`:** if Haiku is unavailable, Sonnet takes over, the same pattern as `a3_place_card_check` (222).
- **Shadow cleared:** the 20% GPT-5.6 Luna shadow on `a3_place_days` was there to help choose the model, and that
  choice is made. Keeping it would only add cost.
- **Migration, not the admin PATCH:** the PATCH needs a staff session with `ai.admin`. A migration also keeps a record
  that can be replayed on a fresh DB, as 213 and 222 do.

## Changed
- `api/migrations/260_place_stages_haiku.sql` updates the two rows and registers itself as version 260.
- `SAFE_DEFAULTS` in `shared/llm_client/role_config.py` mirrors the change.
- `REQUIRED_CIS_SCHEMA` is unchanged, because the code reads the row and does not depend on the migration.

## Tradeoffs
Trial: S246 `place_model_trial`, 3 Laos tours, compared against Sonnet 4.6.

| Model | Decided overnight | Decided anchor | Locate within radius | Cost per tour |
|---|---|---|---|---|
| Haiku 4.5 | 0.95 | 0.89 | 0.53 | $0.011 |
| Luna | 0.74 | 0.79 | 0.76 | not listed |

- Haiku is closer to Sonnet on the day skeleton, which is what the trip map draws.
- Luna is closer on coordinates, but it decides the wrong night about 1 time in 4.
- No model reached the 0.95 bar.
- **Cost of Haiku's coarser coordinates:**
  - The median Haiku point is 21 km from a confirmed point. For Sonnet it is 5 km.
  - The geocoder accepts a candidate only within 25 km of the model's point (50 km in some cases).
  - So more names will fail confirmation and stay `llm` / `area` on `/admin/places`.
