# AA-1188 — tenant reads carry no supplier or commercial data (S295 data-boundary audit DB-01)

## Decisions

- `project_raw` is an **allowlist** (`TENANT_RAW_FIELDS` in `api/routers/_tenant_projection.py`), not a list of hidden
  columns: a column added to `silver_aa_internal.raw_tours` later stays AA-side until someone adds it there. The list
  holds `tour_id` and the trip facts a tenant already reads on `GET /v1/tours/versions/{id}` (`country`, `duration`,
  `inclusions`, `exclusions`) plus the other plain facts (`country_iso2`, `group_size`, `best_time_to_go`,
  `activities`). Out: `provider`, `supplier_id`, `price_raw`, `links`, `manual_facts`, the supplier's source copy
  (`src_*`, `feature`, `period`), import metadata and every pipeline / review / lifecycle / deletion column.
- `TENANT_COMMERCIAL_KEY_RE`: a second key rule next to the AA-770 quality rule `TENANT_FORBIDDEN_KEY_RE`, applied by
  `_without`, the new `_only` and `forbidden_keys` (through `tenant_forbidden_key`). It matches whole `_`-separated
  parts (`net`, `cost(s)`, `margin(s)`, `markup(s)`, `supplier(s)`, `provider(s)`) plus `price_raw` anywhere, so
  `net_amount`, `target_margin`, `supplier_id`, `provider` are caught and `from_price`, `price_usd`,
  `price_usd_monthly`, `overage_usd`, `internet_fee`, `costume` are not (both lists are pinned by tests).
- `GET /v1/marketplace` ("In my catalog") priced each tour with `parse_price(raw_tours.price_raw)`, a number taken
  from the source price text. It now reads AA-Booking's `from_price` by catalog key (`v1_tours._from_prices`, the
  same fail-soft read as the pool, on MAIN after the tenant block). `price_usd` / `price_available` stay for the
  studio card: the from price amount when the currency is USD (today always, price.from.v1 b16), else null. No
  conversion: CIS never computes a price.
- `TENANT_HIDDEN_TOUR_FIELDS` also hides the staff / pipeline columns a `SELECT pt.*` carried (`GET /v1/tours/{id}`,
  the `/full` tenant branch): `generated_content_id`, `approved_by`, `deleted_by`, `master_status_reason`,
  `human_lock_*` (`human_lock_reason` is pii:free_text), `s3_gold_path`, `content_embedding`.

## Changed

- `/v1/tours/pool` and `/v1/tours/versions/{id}` no longer select `rt.price_raw`.
- `/v1/tours/{id}/full` (tenant JWT) returns the allowlisted `raw` only; the X-Admin-Secret branch is unchanged.
- `/v1/marketplace`: `from_price` added; `price_usd` comes from Booking, not from the source text.
- `docs/api/openapi.json` regenerated (the marketplace description).
- The T2 fact lock (`services/content_generation/t2_fact_lock.py` `BASE_SQL`, the tenant `PATCH
  /v1/tours/versions/{id}` edit) no longer reads `rt.price_raw` into its base (review fix). Before, a figure the
  source price text stated was accepted and any other refused, so 20 figures per edit read the source price back,
  and an accepted edit put it into the agency copy that TripPlanner and CRM show travellers. A price the Master or
  the version already states is still accepted.

## Tradeoffs

- The Partner web proxy `/api/tenant/[...path]` still forwards any path (no allowlist); this change makes what
  `/full` returns safe instead. A proxy allowlist is a Partner change, not done here.
- The `/full` tenant branch keeps no source copy (`src_*`): no studio screen reads it, and the supplier's own text can
  name the supplier, its contacts or its prices. The "before" side of a before / after diff is AA's admin view.
- A tour with a source price but no Booking from price now shows no price in "In my catalog" (was an "estimated" USD
  number parsed from the source text).

## Should know

- Partner web follow-up (read-only here): `marketplaceApi.ts` still declares `PoolTour.price_raw` (always absent now,
  harmless) and `MyCatalog.tsx` labels the price "estimated"; it can switch to `from_price` with `FromPriceLine` as the
  Browse tab does.
- The fact-lock base still holds the raw source copy (`src_*`), which can carry the supplier's own figures or
  names: the same accept / refuse answer is a weaker oracle on that text. Narrowing the base to the Master and the
  version is an AA-1144 design change (places named only in the raw source would then be refused), left as a
  follow-up.
- No migration, no data change.
