# AA-901 — CODEOWNERS for sensitive paths (AA-CIS-App)

S247, 22/10/2026, Claude Code. Part of AA-901 (U-25); the decisions are in the root repo (ADR 0011 agent identity
and merge rights, ADR 0014 repo visibility and GitHub plan).

## Decisions

- Owner `@pqnghiep1354` (the repo admin who reviews; looked up read-only with `gh api`).
- Only risky paths are owned: `.github/`, migrations, sign-in / authorization code, agent rules (and, here, the
  paths listed in the file). No catch-all `*` rule, so ordinary PRs never wait for an owner once the gate is on.
- File at `.github/CODEOWNERS`, next to the other GitHub config.

## Changed

- Only `.github/CODEOWNERS` and this note. No branch protection or ruleset change.

## Tradeoffs

- Path-level rules (not a catch-all) keep the future gate narrow; a new sensitive file outside these paths needs a
  new line. Every path in the file was checked against `git ls-files` when it was written.

## Should know

- Branch protection on `main` does not require code-owner review (checked read-only on 22/10/2026: required reviews are off), so the file only adds a review request; the agent still merges after green CI. "Require review from Code Owners" is turned on at the prod trigger (root ADR 0011 decision 4).
