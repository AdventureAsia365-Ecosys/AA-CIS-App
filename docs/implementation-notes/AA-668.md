# AA-668 — Writer panel (Social Content): Goal → Angle → auto-write in a right-side drawer

Session S237, lane cis-portal item 3. Scope this session: Social Content only. The tour-rewrite
writer (CatalogDrawer + LiveWriter) moving into the same panel is a follow-up.

Two branches, stacked:

1. `fix/aa-668-brand-default-cta` (small PR, merge first) — the extra CTA step.
2. `feat/aa-668-writer-panel` (stacked on 1) — the drawer.

## Decisions

- **CTA (part 1):** the write-step effect in `AngleGateWizard.tsx` used to ask the tenant for a
  CTA whenever `angle_gate_request.cta` was NULL, which is every real request. The server already
  falls back to the brand's `default_cta` (AA-771, `service.py` `start_write`: `req.cta or
  cta_override or brand default_cta`). The effect now always calls `write`; the inline CTA field
  only shows on the server's 422 `MissingCTAError` (brand has no default CTA). No backend change.
