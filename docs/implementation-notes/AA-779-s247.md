# AA-779 — S247: two $0 filter bugs from the S246 eval (T9 FAQ real questions)

Earlier notes: `AA-779-s245.md`, `AA-779-real-questions.md`, `AA-779.md`. The S246 eval measured the
real-question chain on a 200-question labelled set (105 KEEP / 95 DROP, kappa 0.913; audit in the private
root repo, `docs/audits/2026-10-21-S246-eval-panels/aa-779.md`) and found two bugs on main that drop questions
the panel keeps. This change fixes only those two; no new gate, no rule tuning. Agent: Claude Code.

## Decisions

- **(a) 'wat' out of `_FOREIGN_WORDS`.** 'wat' is the Thai / Lao / Khmer word for a temple ('Angkor Wat',
  'Wat Pho'). As a Dutch function word it only mattered in a Dutch question; one that starts 'Wat …' already
  fails the English-opener check, and the other Dutch words in the set ('het', 'een', 'hoe', 'waar') catch most
  of the rest. To keep 'Is Wat Pho de moeite waard?' out (it starts with the English opener 'Is' and had only
  'wat'), three Dutch words with no English or Asian-place-name use were added: `moeite`, `waard`, `bezoeken`.
  Rejected: "2+ foreign words" (it would let one-word-marked German/French questions through).
- **(b) landmark kinds are not place names used as words.** New `_LANDMARK_KINDS` (local words for a kind of
  temple / fortress / stupa / shrine: lhakhang, chorten, dzong, gompa, stupa, wat, pagoda, chedi, ger, torii,
  madrasa, …). In `is_off_meaning`:
  - a word-sense cue (`mean`, `meaning`, `the word`, …) no longer drops a question that names a landmark kind,
    unless it also has a junk cue (slang, insult, another word / synonym, spelling, pronunciation, 'how do you
    say') — `_KIND_WORD_JUNK_RE`;
  - a landmark kind is removed from `names` / `lowercase_names`, so 'What is a lhakhang?' no longer hits the
    'a <name>?' common-noun pattern because 'lhakhang' is a token of 'Kyichu Lhakhang'.
  The panel rubric keeps "meaning of a monastery name" as background (aa779-011 'What is a lhakhang?',
  aa779-181 'What does the word "Chorten" mean?').
- Meaning of a plain place name still drops ('What does Punakha mean?', 'What is a moron?'); a meaning question
  that names the landmark ('What is the meaning of Punakha Dzong?') stays.

## Changed

- `services/acp_shared/real_questions.py`: `_FOREIGN_WORDS` (-wat, +moeite/waard/bezoeken), `_LANDMARK_KINDS`,
  `_KIND_WORD_JUNK_RE`, `_asks_landmark_kind`, `is_off_meaning` (kind exemption + docstring).
- `tests/unit/test_aa779_real_questions.py`: temple questions with 'wat' are English; Dutch questions stay
  non-English; `merge` keeps an English 'wat' question from a market tier; landmark-kind meaning questions are
  kept; name / junk-word questions next to landmark kinds still drop; `merge` keeps 'What is a lhakhang?' and
  drops 'What is a moron?'. The new keep-tests fail on main (13 failures on d237c927), pass here.

## Tradeoffs

- A junk question that also happens to name a landmark kind and uses only a meaning cue ('What does moron mean
  near a ger camp?') is now kept; not seen in any PAA data so far.
- The kind list is hand-written and Asia-focused. Missing kinds keep the old behaviour (dropped), which is the
  safe side for a customer-facing FAQ.
