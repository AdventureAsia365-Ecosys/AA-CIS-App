# AA-202 [AA-193·F1-followup] — Brand differentiation

## Context
`shared.tenant_brand_rules` already has columns `brand_type, core_idea, customer_segment,
customer_mindset, voice_examples(jsonb), good_examples`, but the AA-198 resolver only
SELECTed 6 legacy columns → generation never saw them → all 4 brands read alike.
Fix: read + inject these as a structured differentiation block + contrast rule. No migration.

## Decisions
- **`_rewrite_tour` lives in `api/routers/v1_pipeline.py`** (not `services/content_generation/v1_pipeline.py`
  as the task brief guessed). The state-build at line ~111 is the correct wire point. Same intent.
- **Extracted `_build_brand_diff_block(state) -> str` as a pure helper in graph.py.** `generate_node`
  invokes the real LLMClient, so testing it directly needs network/DB mocks. The diff-block logic is
  pure string assembly — pulling it into a helper keeps the AA-202 unit test free of any I/O, mirroring
  the no-DB style of test_aa198_brand_resolver.py. `generate_node` now calls the helper and appends.
- **Added 5 new ContentState TypedDict fields** (brand_core_idea, brand_customer_segment,
  brand_customer_mindset, brand_voice_examples, brand_good_examples) so the state stays typed.

## Changed
- `_BRAND_RULE_COLS` appends: core_idea, customer_segment, customer_mindset, voice_examples,
  good_examples, brand_type (after `version`, all 3 resolver branches share the const).
- brand_rules dict in `_execute_run_tour` gains those 6 keys; voice_examples jsonb→list mirrors the
  existing forbidden_words jsonb handling.
- initial_state in `_rewrite_tour` wires 5 brand_* fields into graph state.
- graph.py: new ContentState fields + `_build_brand_diff_block` helper + call in generate_node.

## Tradeoffs
- Block is injected into `system` (not `prompt`) so it carries brand-level steering, consistent with
  where brand_sp/forbidden_words already live.
- Block condition is OR (core_idea OR cust_mindset OR voice_examples) → old/default brands with none of
  these stay backward-compatible (no block emitted, is_branded logic untouched).

## Should know
- `is_branded = bool(brand_sp)` is unchanged — differentiation block does not affect branded detection.
- No DB seed in this PR (seed is a separate Part 3).
