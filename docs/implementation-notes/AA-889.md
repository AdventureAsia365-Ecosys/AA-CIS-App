## Changed vs. the issue text

- The issue asked to mark the runbook SUPERSEDED "or remove"; a stub with front-matter
  (`status: superseded`) was chosen.
- Redaction was extended from the newly added files to every already-tracked doc, because the Done-when
  covers all CIS docs.
- Cognito pool IDs and company e-mail addresses in docs were left: both are constants in the public code
  already (`api/core/identity_config.py`, `frontend/lib/cognito.ts`).
- API Gateway IDs in old audits were left (they are not in the AA-888 lint list; the old one no longer exists).

## Tradeoffs

- Committing ~100 old notes makes the repo history noisier, but it ends the "local-only docs" split
  (a fresh clone now has the same notes as Nghiệp's laptop) and makes them reviewable.
- The account-ID placeholders lose nothing useful: the account map lives in the private root repo
  (`docs/onboarding.md`, account map).
