## Decisions

- **RLS catalogue owner map first, in its own PR.** `tests/integration/rls_catalogue_rules.py` gains
  `"learn": "cis"`. AA-CIS-Infra keeps a byte copy (`db/rls_catalogue_rules.py`) that its registry test
  compares with `db/owners.yaml`, and the Infra copy guard compares the copy with this repo's `main`. So the order
  is: this one-line PR, then the Infra registry PR (owners.yaml + the copy), then the CIS `learn` migration PR,
  whose Copy Guard reads owners.yaml.

- **CIS 420 (schema `learn`)** is a CONTRACT file (no `-- migrate:` line): CREATE SCHEMA, REVOKE, ALTER DEFAULT
  PRIVILEGES and the DO post-check are outside the expand set. Nine tables per the root design ERD; the CIS RLS
  template on the eight learner-data tables (ENABLE + FORCE, `tenant_isolation` TO `aa_app_user`,
  `<table>_cis_app_all` TO `cis_app`, `<table>_cis_owner_all` TO `cis_owner`); static SQL per table (no dynamic SQL,
  so the lints and reviewers see every policy).
- **`learner.admin_user_id` FK `ON DELETE SET NULL`**; every learner child `ON DELETE CASCADE`; the retention purge is
  the only delete path (`SET LOCAL learn.retention_purge = 'on'` lets the `statement` append-only trigger through,
  also on the cascade).
- **One certificate per (learner, path)** (unique): a renewal updates the row in place (new dates and pinned
  versions, `renewal_reason`); a revocation needs `revoked_at` and `revoked_by = admin:<uuid>`.
- **At most one open quiz attempt per (learner, scope, target)** (partial unique index): the API expires a stale open
  attempt before it starts a new one.
- **Settings keys are `cis.learn.*`** (the registry's key CHECK demands the app prefix): twelve keys, enforced = false
  until the learning API ships. Beyond the plan's list: `cis.learn.verify_requests_per_minute` (30), the public verify
  rate limit, so that limit is a setting too.
- **conftest**: `learn` is dropped with the other replay schemas at session start (a left-over `learn` loses its FK to
  `shared.admin_users` when `shared` is dropped CASCADE), and the eight RLS tables (`X1_420_LEARN_RLS`) join
  `X1_POST_244_RLS` and `X1_POST_245_FORCE_RLS` (244's
  parity-policy test sees only its 16 tables). Comment lines condensed so the file stays at its code-health baseline.

## Slice S4 — the learning API (S281, lane l1-academy-api)

### Decisions

- **Route class `/learn/v1`, its own verifier** (`api/core/learn_identity.py`): WORKFORCE x {`academy-web`} only. The
  Dev client id is a code constant with an env override (the AA-CIS-Infra S2 notes: the CIS task definition does not
  change). A client id equal to a staff client fails closed (503). Refusals: another WORKFORCE client, an M2M or other
  Cognito pool -> 403 `forbidden`; the partner pool -> 403 `partner_not_open`; anything else 401.
- **Learner = active `shared.admin_users` row bound to `(iss, sub)`** (decision 7). No first-sign-in link by e-mail
  here: the staff directory binds an identity on the first CIS admin or CRM sign-in; a person who never signed in
  anywhere else gets 403 `not_a_learner`. Group role (else the DB role) decides `learn.preview`.
- **Certificate name from the staff directory** (review follow-up 3): `learner.display_name` is overwritten with
  `admin_users.display_name` on every call; the client sends no name.
- **Public verify rate limit** (review follow-up 4): key = `login_throttle.client_ip` (rightmost globally routable
  X-Forwarded-For entry: API Gateway appends the real source, the VPC-link NLB adds nothing, the ALB appends a private
  address); limit = setting `cis.learn.verify_requests_per_minute`; one Redis window per minute, in-process window
  when Redis fails. The academy web calls the route from its server, so behind it all visitors share its NAT address:
  the web must limit its own visitors (follow-up for the S5 lane).
- **Captions** (review follow-up "captions over CORS"): no bucket CORS change and no CIS caption route. The API returns
  presigned caption URLs; the academy web fetches them server side (no CORS on a server fetch) and serves the `.vtt`
  from its own origin. The video itself plays straight from S3 (a `<video src>` needs no CORS).
- **Child tenant tie** (review follow-up 1): CIS 421, a trigger (a composite FK cannot express "NULL for staff, equal
  otherwise"), SECURITY INVOKER so a learner hidden by the caller's RLS is refused; a learner's tenant never changes.
  `lab_run (learner_id, module_id, started_at)` index (follow-up 2). Migration-only PR first; this code does not need
  421 (staff rows carry NULL either way).
- **Completion rules**: a lesson completes on a `completed` statement; a module on all lessons + its quiz passed at the
  current major version; labs do not block while closed (P4b). A path without a final quiz certifies when its last
  required module completes (on progress or on the module quiz); with a final quiz only on that quiz. A revoked
  certificate is never re-issued by a pass. Draft modules never count toward a certificate.
- **Grading**: an item that left the bundle between start and submit is left out of the score; a missing response
  counts wrong; an item outside the bound set or answered twice is 422.
- **Review cards**: created once per missed item (new ts-fsrs card, due now); the stored card only moves forward
  (contract checks) with a 120 s clock-skew allowance (a technical constant).
- **Errors**: the contract's Problem body everywhere; path values are shape-checked in the router (404), bodies with
  the pydantic models of `api/schemas/learn.py` (422), so FastAPI's own 422 body never appears.
- **`learn.preview`** joins `staff_authz.ROLE_PERMS` (admin, content_lead) and the `frontend/lib/rbac.ts` mirror.
- **Readiness** requires 420 (`REQUIRED_CIS_ABOVE_GAP`): every learn route answers 503 without schema learn.

### Changed

- The erasure inventory (`services/erasure/inventory.py`) still does not list `learn`: no agency learner can exist
  while the API refuses partner tokens; P7 adds it with the `aa_app_user` grants.
- The `cis.learn.*` keys stay `enforced = false`; a later migration marks them enforced once this code is deployed.

### Tradeoffs

- Per-request learner upsert (one UPDATE per call): keeps the directory name and `last_seen_at` current without a
  cache; the academy's traffic is small.
- Bundle bodies cached per (bundle sha, key), bounded at 128; the manifest for 5 minutes like the docs reader.
