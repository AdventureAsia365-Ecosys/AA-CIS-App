# AA-691 — A1 grounding: master content must be supported by the raw source

Design: `docs/architecture/at-series-v2-design.md` §4.1 A1-1, §8 Q8. ADR 0007 (a Verdict may block or
send back unpublished content, never delete).

## Decisions
- **Measure before wiring (S204).** On the 121 published master tours, the deterministic check (a
  number in the rewrite that the source never states) hits **337 of 7,911 sentences in 90 tours
  (74%)**: 210 itinerary, 87 highlights, 30 summary, 10 subtitle. Typical: "palace grounds cover
  approximately 40 hectares", "situated at approximately 1,900 meters", "Altitude gain today is
  approximately 535 meters". Real-world facts the writer added, not in the source — exactly the class
  that reaches every tenant unchecked today.
- **Sentence-level repair, not flag_fix.** With 74% of tours hit, sending whole fields (mostly
  `itineraries`) through flag_fix's generic rewrite would re-roll day lengths and forbidden words
  (AA-329c / AA-641 history). Instead the grounding node makes **one LLM call per tour** (stage
  `s1_flag_fix`, shared A1 repair config) that rewrites only the quoted sentences against the source,
  applies them by exact replacement, and re-checks. flag_fix is untouched.
- **Numbers fail closed, Jev fails open.** A novel number is a violation unless Jev *confidently and
  enforced* says the sentence is supported (unit conversion, sum). Jev unreachable → the numeric
  check still applies; Jev never blocks on its own unless `a1_claim_supported` is enforced with a
  Calibration Record.
- **Jev question `a1_claim_supported` (migration 186) starts in shadow.** Wording defines the label
  meaning first (Ms. Thư's 51% lesson): mood/colour about something the source names = supported;
  a place, activity, number, meal, service, timing, record or historical fact not in the source =
  not supported. State = `{source, sentence}`; subject key = md5(source)[:10] + md5(sentence)[:12]
  so unchanged sentences re-checked after repair hit the Verdict cache.
- **Units:** subtitle, summary, highlights (one unit per item), itinerary bodies (day-title lines
  skipped). Units under 4 words skipped. Same fields T3 grounds.
- **A1 only.** `is_tenant_rewrite` → passthrough. T2 is grounded against master content by T3, and
  tenant content goes to Jev only via the allow-list (AA-696).

## Changed
- New `services/content_generation/grounding.py` (split, numeric check, Jev, classify, repair).
- `graph.py`: node `grounding` between `brand_audit` and `flag_fix` in both `build_graph()` and
  `build_graph_from_generated()`; `revalidate_node` re-checks grounding at the end — anything still
  unsupported → `manual_check` (HITL), codes re-attached to `failure_codes`.
- ContentState declares `grounding_*` (LangGraph strips undeclared keys — AA-209 gotcha).
- `_rewrite_tour` result + `_build_generated_metadata` carry `metadata.grounding`.
- Migration 186 (shadow question) — **applied on Dev 30/09 before deploy** (additive).

## Tradeoffs
- One Jev call per sentence (~65 per tour, ~$0.006/tour at 29k-char sources) rather than a batch
  form: the seam has no batch asks yet, and batching changes what the calibrated question sees.
- Repair via one Haiku call per hit tour (~$0.002) instead of a full retry (Sonnet rewrite).

## Should know
- Human-edited revalidation (`build_revalidation_graph`) does not run grounding yet.
- Codes `UNSUPPORTED_NUMBER` / `UNSUPPORTED_CLAIM` are not in `_HARD_BLOCK_CODES` (validate never
  raises them); blocking is via `brand_audit_status = manual_check` in revalidate.
- Calibration of `a1_claim_supported` (200 sentences, `docs/calibration/a1_claim_supported.md`): accept
  ≥ 0.90 is 50/50 correct → will clear numeric hits once enforced; the reject side is 11/13 on
  non-numeric sentences → UNSUPPORTED_CLAIM stays shadow. Pending Nghiệp's review of 59 rows.
- Source-number normalisation (`source_number_parts`) cut numeric hits 337 → 302: glued numbers
  (`3h260km`), travel-time conversions (`1h30m` = 90 min = 1.5 h), clock formats (`12.30`).
