# AA-131 — Port 29 Lessons into Rewrite + Editor Prompts

## Decisions

- Target files: `aa_batch_rewrite_v5.py` and `aa_editor_pass_v5.py` (standalone scripts, not `services/content_generation/`).
- Lessons with Stage=audit (7, 9, 16, 18) → NOT implemented in prompts; commented `# AA-133 audit script`.
- Lesson 11 (SEO completeness gate) → implemented in `aa_editor_pass_v5.py` as a new `seo_incomplete` status.
- `normalize_name()` added as a preprocessing function called inside `build_rewrite_source()`, so it runs before any LLM call.
- `LESSONS_ADDENDUM` added as a module-level constant in the rewrite script; injected into `build_editorial_prompt()` between Rules and Source blocks.
- Lesson 13 (day count vs duration): validated against itinerary day marker count (not DURATION field, which is not passed to `validate_final_payload`).

## Tradeoffs

- "vibrant" and "seamless" added to BANNED_WORDS — will flag rare legitimate uses. Acceptable given brand strictness.
- "fun" added to BANNED_WORDS — could flag "fun" in itinerary prose. Acceptable; AA copy should avoid this word anyway.
- Lesson 17 (highlight ordering check) implemented as a comment/editorial prompt rule only — runtime ordering validation requires knowing which highlights are primary-activity vs secondary, which needs semantic judgment, not regex.
- Lesson 7 (sibling tour cross-batch deduplication) and Lesson 16 (portfolio name collision) — both require cross-tour context unavailable in single-tour validation; deferred to AA-133.

## Should know

- New failure codes: `SUBTITLE_CITY_LIST_OR_WAYPOINT`, `SUBTITLE_DAY_COUNT_MISMATCH`, `HIGHLIGHT_CONDITIONAL_LANGUAGE`, `META_PATTERN_REJECTED`, `TRIP_TYPE_SEO_MISMATCH`, `NAME_SUPERLATIVE_DETECTED`.
- `is_content_failure()` and `is_seo_failure()` in `aa_editor_pass_v5.py` updated to classify new codes.
- `seo_incomplete` is a new editor status for tours where SEO fields are empty after rewrite (Lesson 11).
