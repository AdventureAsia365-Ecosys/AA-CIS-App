# AA-794 — T2 SEO meta cut mid-sentence + wrong-country suffix

Branch `fix/aa-794-t2-meta` (S235, lane A-T2, Claude Code). First commit on the branch is the A1
prompt golden-SHA guard (`tests/unit/test_aa792_a1_prompt_golden.py`, captured on main @20a2387)
that AA-792 stacks on.

## Decisions
- **Fix the cut, not the global check.** The fragments ("…mountain valleys with expert.") come from
  the last-resort word-boundary cut in `seo_meta_utils._cut_long_meta`. A word cut is now taken only
  right BEFORE a word that opens a new phrase (`_META_CUT_BEFORE`: the BAD/WEAK ending connectors +
  across/through/along/past/toward(s)/while/where/which/before/after/during/among/via/into/around).
  No clean cut in band → `None` → the meta is returned unchanged, `SEO_META_TOO_LONG` stays, and the
  existing flag_fix LLM meta repair (`_rerepair_meta`, Haiku, ~$0.001) rewrites it. No new LLM path.
- **Articles, "of" and "as" are NOT cut points** (narrower than the plan's boundary set). Cutting
  before them usually leaves a dangling verb or noun ("visits | the dzong" → "visits.",
  "a series | of" → "a series."). Cheaper to fall back to the LLM repair than to ship that.
- **meta_complete_sentence** now also rejects `_META_WEAK_ENDINGS` (a, an, the, by, of, via, into,
  through, between, as). The deterministic fit already strips these, so `META_INCOMPLETE_SENTENCE`
  keeps its deterministic repair (lesson S218 / AA-736: a hard code must name its fix). **No
  noun/adjective heuristic** in the global check: it hard-blocks A1 Master and human-edit approve
  and nothing can fix a noun ending deterministically.
- **Country tail.** `_extend_short_meta` skips every `in <country>` tail when the tour name or the
  meta names any country other than `facts.country` (canonical names + word aliases of 4+ letters
  from `shared/country_resolver.COUNTRY_MASTER`; short codes like LAO/IND/PRC are ignored as words).
  Days-only tails are still allowed. `raw_tours` has no multi-country column, so the tour name is
  the only reliable signal (the T2 tour dict's `name` is the A1 `aa_name`).
- **T3 parity.** `run_t3_qa_gate` now calls `fit_seo_meta_final(meta, {duration, country, name},
  forbidden)` instead of `fit_seo_meta` (salvage only), so an over-long one-sentence meta is cut
  deterministically before a length code triggers a whole-tour Sonnet rewrite.
- **Observability.** `seo_meta_fit_unresolved` (reason `too_long|too_short|incomplete`, `len`) is
  logged when the deterministic fit leaves the meta out of band — the count of LLM fallbacks.

## Changed
- `services/content_generation/seo_meta_utils.py`: `_META_CUT_BEFORE`, `_next_word`,

- Not changed: the writer prompt's meta aim (LLM character counting is weak, S233 — out of scope).

## Tradeoffs
- More metas now fall through to the LLM meta repair instead of a deterministic word cut (≈$0.001
  per call on Haiku). Measured by `seo_meta_fit_unresolved reason=too_long` on the rerun.
- A meta that names a country only in passing ("Japanese gardens" on a China tour) also loses the
  country tail. Conservative on purpose: a missing country is harmless, a wrong one is not.
- Weak-ending rejection is global: an A1/T2 meta ending "… of." / "… the." now fires
  `META_INCOMPLETE_SENTENCE`. The fit strips the weak word and re-closes the sentence, so it is a
  deterministic fix, never a stuck tour.
