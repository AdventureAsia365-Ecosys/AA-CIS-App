# AA-631 — Debate stage for Slate: follow-up (S203, 29/09/2026)

The original build (S193, PR #423) has no notes file in this repo; see the S193 session log. This file covers the S203 fix only.

## Problem
- `acp_shared.debate_brand_fit_cache` held 2 rulings, both **judge_score 1.0**. The judge's feedback: "Replace the repeated placeholder text…", "Remove the repeated, corrupted text…".
- `_fetch_candidate_text()` pasted the same joined atom text into `summary` (cut at 800 chars), `highlights` and `itineraries` (cut at 600) of a fake tour page, and Debate scored it with the **rewrite** judge (`score_brand_fit`).
- Structural issue, independent of the duplication: the rewrite prompt asks whether the brand's mission surfaces in each day's itinerary. Raw atom text never does, so `mission_absent_cap` (6.0) capped every fresh candidate below `BRAND_FIT_CUT_THRESHOLD` (7.0). Brand-fit therefore flagged every candidate it scored, and only the 50% safety rail limited the cut.

## Decisions
- New `score_candidate_fit(brand_profile, {"place", "action", "evidence"})` in `brand_fit.py`, with its own system and user prompt. It judges whether the **topic** suits the brand (who the travellers are, what they want) and whether the evidence gives the brand material for its own angle. There is no mission axis and no cap.
- It keeps AA-631's decision to share one module: same `s1_judge` stage route, temperature/seed, JSON parsing and `BrandFitResult` shape. The common part is now `_judge()`. `score_brand_fit()` (T2 `judge_node`) is unchanged in behaviour, and its 6.0 mission cap is covered by a test.
- Evidence = distinct atom texts (whitespace-normalised, casefold dedupe), at most 12, each ≤ 240 chars. It is labelled in the prompt as unedited catalogue text, so plain or repetitive wording is not read as corruption.

## Tradeoffs
- The Debate score and the later T2 rewrite score are no longer produced by the same prompt. That is intended: one judges a topic before writing, the other judges finished copy. They were never comparable, because raw text cannot pass a copy judge.
- The cut threshold stays 7.0. The probe shows a generic topic landing just under it and a distinctive one on it, so the threshold looks usable as is. It should be revisited once there are more rulings.
