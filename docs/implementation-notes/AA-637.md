# AA-637 — Live writing progress (steps + streamed text)

## Decisions
- Option 1 from the issue (Redis snapshot + ~0.8s poll), recorded as `docs/adr/0004`. No SSE, no
  API Gateway change.
- Sink bound per job with a ContextVar; asyncio.to_thread and LangGraph's run_in_executor both
  copy context (verified in langchain_core/runnables/config.py::run_in_executor).
- Satellite (`invoke_claude`) streams only when given `on_delta` — every other caller keeps the
  exact old non-streaming invoke_model request.
- Streamed stages: t9_write, t2_generate, s1_generate. Judge/brand-audit → "Checking" step;
  flag-fix/itinerary-nudge → "Polishing" step; never shown as text.
- Server shapes the display (partial-JSON → labelled sections, citation tags stripped incl. a
  half-written trailing tag, `===SUMMARY===` tail hidden). Client never sees raw output.
- Redis missing / erroring → no live view, job unaffected (`getattr(app.state, "redis", None)`).

## Changed
- New: stream_sink.py, writing_progress.py, v1_progress.py, LiveWriter.tsx, ADR 0004, tests.
- LLMClient.generate() split into generate() (reports call start/end) + _generate(); every
  provider attempt reports a restart (drops partial text from a failed provider).
- T9 router wraps run_write_background in `_run_write_with_progress`; service marks "check".
- T2 trigger_rewrite wraps `_do_rewrite_and_save`; marks "check" before T3 QA, "save" before the
  UPDATE, and `progress_fail()` on its handled exception path.
- Portal: AngleGateWizard writing state and CatalogTab "Writing your tour" panel use LiveWriter.

## Tradeoffs
- Poll (not push) = up to ~1s latency, but survives reloads/tab switches and multi-task ECS.
- Typewriter animation smooths the 0.4s/0.8s chunking client-side; respects reduced motion.

## Should know
- test_aa450 strong-ref test: other tests' write() tasks can outlive their event loop now (the
  wrapper takes a few more ticks), so the test clears the shared set first.
- OpenAI last-resort path does not token-stream; the live view gets the whole text at once.
