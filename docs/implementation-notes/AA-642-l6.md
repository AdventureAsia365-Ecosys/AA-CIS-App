# AA-642 L6 — CI guard against calls that bypass the gateway (CIS part, slice G1)

Plan: root `docs/audits/2026-11-01-S263-gateway-gap-audit/plan.md` §1.G (G1). Sibling guards in AA-TripPlanner-Web,
AA-Partner and AA-Booking (G2) ship as their own PRs.

## Decisions

- **Extend the existing AA-685 test, not a new file.** `tests/unit/test_aa685_no_raw_model_calls.py` already holds
  the rule and CONTEXT.md points at it. New patterns: `apply_guardrail`, `create_model_invocation_job`, the vendor
  SDK resources `.completions/.messages/.responses/.embeddings` with `.create/.stream/.parse`, importing `openai` /
  `anthropic`, and vendor endpoint strings (`api.anthropic.com`, `api.openai.com`, `bedrock-runtime`).
- **Endpoint strings, not httpx/requests call shapes.** A URL constant is the common factor of an httpx, requests or
  urllib call (and of a boto3 `bedrock-runtime` client), whatever the call looks like. Docstrings are skipped;
  comments are not in the AST.
- **Roots** now include `worker/` and `scripts/` (ad-hoc scripts must go through `LLMClient.generate()` and write
  `llm_call_log` too). `tests/` stays out: tests patch the clients.
- **ALLOWED keyed by (path, hit) with a ratchet.** The old list was path → reason (a whole file exempt). Now an entry
  exempts one kind of hit in one file, and an entry that no longer matches fails (`test_allowlist_entries_still_match`),
  like the AA-642 `model_tier` ratchet.
- **Attributes, not only calls:** `asyncio.to_thread(rt.converse, ...)` passes the method uncalled (the CRM adapter
  does exactly this), so a Bedrock method or SDK `resource.verb` attribute counts wherever it appears.
- **Detector self-test** on invented snippets: each pattern must be caught, docstrings/comments/unrelated
  `.messages.send()` / `.create()` must not.

## Changed

- Plan item "delete 6 legacy acc1 scripts": on `main` 0982cbd9 there are none. `git grep` for the retired personal
  account id returns nothing (scrubbed by #854); a case-insensitive search for acc1 / its role / profile names outside
  `docs/`, migrations and tests finds only hash fragments in `.github/golden_text_fingerprints.txt` and
  `prompt_versions.json`. The AA-998 guard (`test_aa998_no_acc1_runtime.py`) already blocks the role, profile and
  env var. Nothing deleted.

## Tradeoffs

- `.messages.create` could match a non-LLM API with a `messages` resource. None exists today; such a site would be
  added to ALLOWED with its reason.
- The scan found **no real bypass**. The only allowed hits are the S10 cost reconcile's billing endpoints
  (`services/llm_cost/reconcile.py`, organization cost report / costs; no model call).
